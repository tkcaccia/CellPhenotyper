# CellPhenotyper metro map

This directory contains two views of the Nextflow workflow:

- `cellphenotyper_nextflow_dag.mmd`: the technical Mermaid DAG generated by Nextflow.
- `cellphenotyper_metro.mmd`: the curated, route-oriented source used for the publication figure.
- `cellphenotyper_metro.svg`: the static publication and README asset.
- `cellphenotyper_metro.html`: a self-contained interactive map with route filtering.
- `cellphenotyper_metro_preview.png`: a raster preview for rapid visual review.

The curated map is a biological-route overview rather than a literal process DAG. It omits internal channels, joins, placeholders, report-only edges, restart plumbing, and secondary optional branches such as TMA annotation.

The map reads from left to right:

1. One H&E input is converted with physical-resolution metadata and passed through GrandQC.
2. Whole-tissue and optional ROI-restricted tissue crops are alternative routes that reconverge as one analysis-ready crop.
3. Pathway A creates an overlapping spatial grid whose inner cores are adjacent, extracts fused UNI-2 tile and inner-centre features, and runs its own PCA, KODAMA, and Leiden analysis.
4. Pathway B runs StarDist, HoVer-Net MoNuSAC, and CellViT++ in parallel. Role-aware instance fusion requires spatial agreement between broad-scope StarDist and CellViT++, while MoNuSAC contributes scoped corroboration and detector-specific phenotype evidence.
5. Pathway B1 extracts fused UNI-2 whole-tile and 90-pixel inner-square features from cell-centred tiles and runs an independent PCA, KODAMA, and Leiden analysis.
6. Pathway B2 generates the GigaTIME virtual mIHC image, quantifies markers in nuclear and cell regions, and runs a marker-specific PCA and KODAMA analysis.
7. The cell-centred route grows sparse cell-supported labels through tissue before GPU MedSAM refinement. The grid route already has adjacent dense inner-core labels, so it bypasses tissue growth and sends the grid cluster mask directly to MedSAM. Both routes then export phenotype GeoJSON. Optional section-level TITAN and PathoFMPred analysis follows the reconstructed tissue phenotypes.

## Implementation status

The metro map now matches the executable `--uni2_sampling_mode both` topology. The unsuffixed grid route and `<sample>__cells` route run independent UNI-2, KODAMA, Leiden, mask, MedSAM and GeoJSON stages. The cell route alone includes tissue growth. A clustering-to-GeoJSON Nextflow stub run verifies both branches and their restart inputs; biological route selection still requires the independent paired validation described in `docs/UNI2_ROUTE_VALIDATION_PROTOCOL.md`.

## Regenerate the technical DAG

Nextflow preview mode constructs the complete graph without executing tasks. GPU topology is requested because TITAN and PathoFMPred are guarded GPU stages.

```bash
nextflow run main.nf \
  -preview \
  -with-dag docs/pipeline_metro/cellphenotyper_nextflow_dag.mmd \
  --image_input Data/ROI_A.ome.tif \
  --roi_geojson Data/ROI_A.geojson \
  --run_full_pipeline true \
  --start_point convert \
  --end_point pathofmpred \
  --cell_consensus_enable true \
  --tma_enable true \
  --gigatime_enable true \
  --uni2_sampling_mode both \
  --titan_enable true \
  --pathofmpred_enable true \
  --pathofmpred_cancer BRCA \
  --compute_device gpu \
  --host_arch amd64 \
  --outdir_base /tmp/cellphenotyper_dag_preview
```

The automatic conversion is useful as an audit aid, but it contracts Nextflow's anonymous channel nodes and can misrepresent complex join topology. The maintained publication source is therefore `cellphenotyper_metro.mmd`.

## Render the curated map

Install `nf-metro` in an isolated environment:

```bash
python3 -m venv /tmp/cellphenotyper-nf-metro
/tmp/cellphenotyper-nf-metro/bin/pip install nf-metro
```

Validate and render:

```bash
/tmp/cellphenotyper-nf-metro/bin/nf-metro validate \
  docs/pipeline_metro/cellphenotyper_metro.mmd \
  --with-layout --strict

/tmp/cellphenotyper-nf-metro/bin/nf-metro render \
  docs/pipeline_metro/cellphenotyper_metro.mmd \
  -o docs/pipeline_metro/cellphenotyper_metro.svg \
  --responsive --embed-font --validate --strict

/tmp/cellphenotyper-nf-metro/bin/nf-metro render \
  docs/pipeline_metro/cellphenotyper_metro.mmd \
  --format html \
  -o docs/pipeline_metro/cellphenotyper_metro.html
```

The `%%metro process:` directives map stations to their Nextflow process names, so the same curated definition can later be used with `nf-metro serve` and Nextflow `-with-weblog` for live run status.
